O [GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent) permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui uma tarefa no GitHub, e o cloud agent a executa em segundo plano — explora o repositório, faz alterações e abre um pull request — enquanto você pode se dedicar a outras atividades.

Ao longo destes exercícios, você vai adicionar instruções personalizadas para o agente seguir e, depois, atribuir uma issue do GitHub para que ele implemente o trabalho. Vai revisar e usar agentes personalizados para orientar a abordagem, monitorar e direcionar sessões no painel de agentes e, por fim, revisar os pull requests e iterar sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O GitHub Copilot cloud agent habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes verificados podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e os recursos do Copilot CLI usados neste workshop — portanto, você pode concluir todos os ambientes com ele.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O cloud agent está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — todos, exceto o Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitá-lo para a organização.

> [!NOTE]
> Este ambiente não aborda MCP. Para explorar o uso de servidores MCP com o Copilot, consulte o [ambiente de CLI][cli] ou o [ambiente do VS Code][vscode].
